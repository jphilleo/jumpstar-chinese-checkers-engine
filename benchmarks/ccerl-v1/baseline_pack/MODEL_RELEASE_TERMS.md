# CCERL Baseline Model Release Terms

Status: maintainer draft for the `CCERL-2P10-v1` baseline model artifacts.

The `.ccpv` model files in the CCERL baseline pack are provided for benchmark,
research, reproducibility, and engine-comparison use with the public Chinese
Checkers Engine Rating List.

You may:

- download and run the baseline models for CCERL evaluation
- redistribute the unmodified model artifacts with their SHA256 hashes
- publish benchmark results that identify the exact model label and hash
- use the models as fixed opponents or reference baselines

You may not:

- claim authorship of the baseline model artifacts
- publish modified model files under the original CCERL labels or hashes
- imply that CCERL engine Elo is human Elo
- count self-reported games in the official rating list without runner
  verification

The model artifacts are provided as-is, with no warranty. Before external
publication, the project maintainer should confirm whether these draft terms are
the intended public license or replace them with a standard license.
