# Benchmark Documentation

These files define the public CCERL benchmark and the public JumpStar launch
evidence.

- [CCERL-2P10-v2.md](CCERL-2P10-v2.md): current public ruleset.
- [CCP_PROTOCOL.md](CCP_PROTOCOL.md): stdin/stdout engine protocol and referee
  contract.
- [CCERL_LEADERBOARD.md](CCERL_LEADERBOARD.md): current leaderboard snapshot.
- [CCERL_SUBMISSIONS.md](CCERL_SUBMISSIONS.md): external engine submission modes
  and resource classes.
- [PUBLIC_BENCHMARK.md](PUBLIC_BENCHMARK.md): benchmark structure and launch
  path.
- [RULE_PROFILES.md](RULE_PROFILES.md): C++ rule-profile mapping.
- [OPEN_SOURCE_BOT_SCREENING.md](OPEN_SOURCE_BOT_SCREENING.md): open-source bot
  survey and source-style ladder results.
- [CHANGELOG_2P10_V1_TO_V2.md](CHANGELOG_2P10_V1_TO_V2.md): v1-to-v2 rule
  revision details.
- [CCERL-2P10-v1.md](CCERL-2P10-v1.md): frozen historical v1 ruleset.
